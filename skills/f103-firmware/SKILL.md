# STM32F103 固件开发（HAL1）

只写 HAL1（`stm32f1xx_hal_*.h`）的应用代码，不套用 HAL2 接口。时钟、引脚复用与中断优先级以目标芯片参考手册和本板原理图为准。

1. 先建立时间基准：`HAL_Init()` 建立 1 kHz SysTick，`SystemClock_Config()` 之后 `HAL_Delay` 才准确；72 MHz = HSE 8 MHz × PLL9。
2. 使用任何外设前开时钟：`__HAL_RCC_*_CLK_ENABLE()`。漏开时钟不报错，表现为引脚无反应或读到 0。
3. 模块引脚、例程位置与占用见[模块清单](references/modules.md)。组合多个模块前先核对该文的冲突表，必要时改 `bsp_*.h` 的引脚宏。
4. I2C 器件不要假设引脚：同一模块在核心板排针与扩展板插座的引脚不同，先用探测确认应答地址，见[I2C 探测](references/i2c-probe.md)。
5. 持续收数据的串口模块用中断逐字节收，回调中重新武装，见[UART 收发](references/uart.md)。
6. 阻塞式器件（单总线传感器等）会拉长主循环，需评估其对串口与其他时序的影响；必要时降采样而非阻塞等待。

完成时说明改动了哪些外设、引脚如何分配、以及验证到哪一步：

- **编译验证**：能编出 ELF，未上板
- **板端验证**：烧录后行为符合预期

不把"编译通过"表述为"功能可用"；改动外设后不沿用旧的验证结论。
